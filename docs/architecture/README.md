# Architecture Documentation

The MVP architecture reference is intentionally shorter and more durable than
the detailed planning notes and product prototype, which remain versioned in
this repository.

- [MVP architecture](./mvp-architecture.md): the implemented domain model, API/UI boundaries, simulation seams, security, and verification.
- [MVP prototype](../product/aiworld_mvp.html): visual and interaction reference for the observer and admin experiences.
- [MVP implementation plans](../plans/README.md): dependency-ordered product and engineering plans with test and browser verification records.

Post-MVP capabilities such as human participation get their own plan and
architecture note rather than rewriting the implemented MVP reference.
